## Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/conecta-lar.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd conecta-lar
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```

## Uso

1. Execute a aplicação:
   ```bash
   npm run dev
   ```
2. Acesse no navegador:
   ```
   http://localhost:5009
   ```
